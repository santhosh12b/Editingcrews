# Editingcrews

Professionelle KI-Videoproduktion & Videoschnitt für Produkte und Dienstleistungen.

## Features
- **3D 360° Rotating Carousel** for mobile & tablet video previews
- **Full-Screen Vertical Video Reel Player** with modal playback & audio controls
- **Multilingual Support**: Deutsch, English, Français, Español, Italiano
- **Pricing & Inquiry Calculator**: €69 / minute with dynamic order summary
- **Interactive Showreel & Services Showcase**
- **Modern Responsive Design** powered by React & Tailwind CSS

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
